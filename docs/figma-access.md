## ⚠ 페이지 목록 조회가 깨져 있다

`get_metadata` 를 **nodeId 없이** 호출하면 `Cover` 페이지 하나만 돌아온다. 실제로는 페이지가
11개다. 파일 링크만 받고 "화면이 안 보인다"고 판단하면 안 된다.

**우회:** `list_file_components_for_code_connect(fileKey)` 를 호출하면 각 컴포넌트 항목에
`pageId`/`pageName` 이 딸려 나온다. 거기서 페이지 ID를 전부 얻는다. 아래가 그렇게 확보한 목록이다.

## 화면 프레임 찾기

페이지 ID로 `get_metadata(fileKey, pageId)` 하면 그 페이지의 최상위 프레임이 전부 나온다.
- 프레임 이름은 `PC_지역경찰_06_장비관리_03_무기` 형식이고 `MO_` 접두는 모바일이다.
- 결과가 크다(지역경찰 페이지 889KB) — 파일로 저장되므로 최상위 프레임만 추려 읽는다.
- `Label 3 Depth`, `작업상태`, `Redlines`, `Note` 같은 항목은 디자인 주석·마커라 화면이 아니다.

프레임 이름 → 화면ID 대응은 `screen-id-map.md` 참고. **Figma 메뉴 번호로 화면ID를 유추하면
틀린다**(예: `06_장비관리` → `PC-LPO-07xx`).
